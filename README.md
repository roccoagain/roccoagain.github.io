# roccoagain.github.io

## Artifacts

> The Artifacts section is hidden for now because it's empty. To bring it back, uncomment the Artifacts link, the `#artifacts` section and the `artifacts.js` script tag in `index.html`, then renumber Activity back to [04].

Any top-level folder with an `index.html` (like `demo/`) is listed on the homepage automatically. The list uses the page's `<title>` and `<meta name="description">`. To keep a page off the list, add `<meta name="artifact" content="hidden">`.
